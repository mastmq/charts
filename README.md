# charts

Helm charts for [mast](https://github.com/mastmq/mast), a multi-tenant MQTT broker built on core NATS.

| Chart | Description |
| --- | --- |
| [mast](charts/mast) | The broker, in standalone or clustered form |

## Install

```console
$ helm install mast oci://ghcr.io/mastmq/charts/mast
```
